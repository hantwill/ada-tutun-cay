## ⏳ Geriye Kalanlar

### KRİTİK (v1.1.0 için)

| # | Sorun | Açıklama | Kim Buldu |
|---|-------|----------|-----------|
| K1 | **Backend yetki kontrolü yok** | Her kullanıcı her Tauri komutunu çağırabilir. `kullanici_sil`, `db_yedekle_yol` gibi admin komutları frontend'de gizli ama backend'de açık. | Kimi + MiniMax |
| K2 | **Tuzsuz SHA-256 şifre hash** | Rainbow table saldırısına açık. `argon2` veya `PBKDF2` + tuz kullanılmalı. | Gemini + Kimi + MiniMax |
| K3 | **`satis_yap` fiyatları frontend'den geliyor** | `birim_fiyat` ve `toplam` frontend'den gönderiliyor, manipüle edilebilir. Backend DB'den fiyat okumalı. | Kimi + MiniMax |
| K4 | **Default admin şifresi `admin123`** | İlk girişte zorla değiştirme akışı yok. | Kimi + MiniMax |
| K5 | **`kullanici_sifre_degistir` eski şifre kontrolü yok** | Herhangi biri kullanıcı ID'sini bilirse şifreyi değiştirebilir. | MiniMax |
| K6 | **`db_geri_yukle_yol` açık connection** | Mutex kilitlenmiyor, SQLite connection açıkken dosya üzerine kopyalanıyor. DB bozulma riski. | Gemini + Kimi + MiniMax |

### ORTA (v1.1.0/v1.2.0 için)

| # | Sorun | Açıklama |
|---|-------|----------|
| O1 | **POS.tsx `miktarDegistir` stok kontrolü yok** | Sepette miktar artırınca stok sınırı kontrol edilmiyor. |

| O11 | **Cargo.toml `chrono` yorum yanlış** | "kullanilmiyor" yorumu yanlış, `chrono::Local::now()` kullanılıyor. |
| O12 | **CSP `connect-src` production'da geniş** | `localhost:*` production'da gereksiz. |
| O13 | **Windows MSI hasarlı** | WiX toolset CI'da bazen başarısız. NSIS alternatif düşünülebilir. |
